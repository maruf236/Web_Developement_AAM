Let's make Favicon: 

            The question arise what is favicon ? 
        =>  Ans: The photo we see beside a browser link is the favicon. 
            Sometimes set the image of the webpage name or the logo of the 
            page . To learn it we will also create a page that has favicon. 
            Let's see with html...........
            < link rel="icon" type="image/png" href="Photos_prac/text_f.png" >
            
            here,
            < link >= Connect the HTML document to an external resource.
            
            rel ="icon" tells the browser that the resource is the webpage's icon.
            
            type="image/png" specifies that the image format is PNG.
            
            href="......." path link of the photo.
